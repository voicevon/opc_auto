🚀 宿主 Chrome 9222 调试端口启动指南
核心原理：系统通过原生 CDP 协议接管您真实的本地 Chrome，直接复用您已登录的淘宝/京东 Cookie，杜绝任何滑块风控。
  1. 第一步：关闭已有普通 Chrome 窗口
    若 Chrome 正在运行且未开调试端口，Chrome 单例机制将阻止开启端口。请先保存工作并关闭普通 Chrome 窗口。
  2. 第二步：双击启动脚本
    在项目根目录下双击运行：start_chrome_debug.bat
  3. 第三步：登录并保持页面开启
    在启动的浏览器窗口中登录淘宝，并打开『已买到的宝贝』列表页，保持该窗口开启。
  4. 第四步：自动采集或一键核验
    刷新本系统工作台，状态栏将变为 🟢 CDP 9222 已连接。点击右上角【⚡ 立即执行交叉核验】即可全自动抓取与对账；每日定时执行由 Trae 自动化托管。
