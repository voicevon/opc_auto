# 电子税务局与数电发票查验指南 (ETax & Invoice Verification Guide)

> **使用说明**：
> 本文记录公司如何通过国家税务总局官方系统获取、查验及核对进项增值税发票（数电发票、纸质转电子专票等），作为本自动化系统进项发票数据的最终权威来源。

---

## 二、 数电票时代：进项发票如何自动“被动到账”

在国家推行**全面数字化的电子发票 (数电票)** 后，企业的受票逻辑发生了根本性变革：
1. **无需向税局主动申报录入**：
   - 只要任何销售方商家（无论是在淘宝、京东、加油站还是线下实体）在他们开票软件中正确填写了贵公司的**企业名称与统一社会信用代码 (91310000XXXXXXXXXX)**；
   - **该张发票在商家开出的一瞬间，就会自动实时同步流转进入贵公司在电子税务局的【税务数字账户 - 发票勾选】底账库中**。
2. **本系统的对账核心机理**：
   - 我们的系统只需要从电子税务局拉取进项受票清单；
   - 凡是在税局底账中出现的，代表**法律上已经生效并属于公司的进项票据**；
   - 若某笔淘宝/京东订单在税局底账中查不到，**100% 证明商家尚未真正开票**，必须触发催票流程！

## 三、 电子税务局数据同步操作方式 (两套方案)

### 方案 1：税务数字账户 Excel 底账手工/定时导出导入 (0风险稳定方案)
1. 财务登录【国家税务总局新电子税务局】；
2. 进入【我要办税】➔【税务数字账户】➔【发票勾选】➔【抵扣类勾选】；
3. 选择查询区间（如近 30 天或本月），点击【导出当前页 / 导出全量发票明细 (.xlsx)】；
4. 将导出的 Excel 拖入本系统 Web 界面或放入指定同步文件夹，系统自动完成解析与四分类匹配。

### 方案 2：RPA 浏览器自动化拉取 (技术预研)
1. 在内网财务电脑上由 Playwright 启动专用受控浏览器；
2. 财务人员每日人脸识别扫码一次完成会话保活；
3. 机器人定时调用接口拉取进项受票列表 JSON 数据并存入 SQLite/PostgreSQL 数据库。

## 四、 常见税务状态对照字典

| 税局状态编码 | 状态名称 | 含义说明与系统应对策略 |
| :--- | :--- | :--- |
| `01` | **正常** | 有效合法发票，可正常参与订单核销与税额抵扣。 |
| `02` | **作废** | 商家开具后已作废，系统必须报警并剔除匹配绑定。 |
| `03` | **已红冲** | 商家开具了负数红字发票（通常发生于退货退款），系统需生成红冲对冲单。 |
| `04` | **异常凭证** | 税务稽查锁定的走逃失联商家发票，系统立即标红发出财务风险警报。 |
