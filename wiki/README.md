## 🎯 知识库与系统的联动关系

- **Wiki 是系统的知识真理源 (SSOT)**：
  - 自动化脚本爬取与提交发票申请时，其企业抬头直接依赖 `01_企业开票信息与抬头规范`；
  - 采购渠道适配器（Adapter）的 URL 与选择器依据 `02_采购平台与发票获取指南` 维护；
  - 智能对账引擎的数据结构与合法性校验规则依托 `03_电子税务局与数电票查验指南`。
